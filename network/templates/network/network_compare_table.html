How to read this page

This page sets two analyses side by side: the one this export belongs to (This analysis) and a second one chosen for comparison (Compared analysis), for instance another period or another selection of channels.

The first table gives each whole-network statistic for both. A dash means the statistic was not computed in that analysis. A difference means something only where the two analyses were built the same way: the same weighting of ties, the same kinds of channels, the same community methods. The methods record of each analysis lists its settings.

Several statistics depend on size alone: density falls and path lengths grow as a network gains channels. Compare networks of similar size, or read those rows with that in mind.

The histogram and the scatter plot overlay the two sets of channels. The scatter's axes are logarithmic, so a channel with a zero on either measure is left out; normalising rescales each analysis to its own 0–1 range, which compares shapes rather than sizes. The dashed lines are each analysis' power-law trend.

Degree distribution

How many channels of each analysis fall in each band of in-strength or out-strength: the summed weight of the ties a channel receives or sends, its weighted degree.

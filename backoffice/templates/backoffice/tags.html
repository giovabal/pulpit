Message tags

Informal, shared bookmarks for messages: tag a message from the button on any post card, then find it again through the tag filter in a message list's Options menu or by typing tag:name in a search box. Tags never affect the analysis. New tags get the next free palette colour; change it here. Merge folds a tag's messages into another tag and deletes it.
